# 网页 GUI（服务端渲染页面）

## 页面（服务端渲染，禁用 JS 也能完整使用）

| 路径 | 页面 |
| --- | --- |
| `/` | 首页：检索框、规模数字、常用法律、疑难注解精选、被司法解释引用最多的条文、最新公布 |
| `/divisions` · `/division/:id` · `/domain/:id` | 编总览 → 编内领域 → 文件列表 |
| `/d/:docId` | 法律总览：侧栏**目录树**（编/分编/章/节（最深到节）、逐级展开收起、按当前浏览位置自动展开高亮（只保留当前条文所在的一支展开，用户手动展开的分支保持展开，其余自动收起）、章节链接自动跨页到 `?from=` 并标注“你在这里”）+ 条文目录（可 `?from=101` 翻页、`?q=` 过滤；换章/换节处插入标题分隔行，落在章节中间时标“续”）；关联概览 / 本书的疑难注解 / 关联指导性案例排在目录之后；`?a=585` 直达条文 |
| `/d/:docId/:number` | **条文页**（结构见[司法解释如何挂到法条下](interp-linking.md)）。`:number` 支持插入条 slug，如 `/d/criminal-law/120-1`；已撰写条旨的条文，标题会排成「第三条 【罪刑法定原则】」 |
| `/search` | 检索（参数见[全局检索](search.md)）。进页方式：页顶搜索框留空点“检索”→ `/search`（浏览全库，会把浏览器提交的空 `q=` 规范化为干净的 `/search`）或直接输入关键词 |
| `/notes` | 疑难注解索引（`?level=key&division=civil`） |
| `/cases` · `/case/:id` | 指导性案例列表 / 详情（含关联法条跳转） |
| `/about` | 数据来源、口径说明、已知边界 |
| `/health` | 健康检查（返回文档数与条文数） |

前端增强（`public/app.js`，6.7 KB，零依赖）：检索条件改变即提交（范围/类型/排序下拉）、`/` 聚焦搜索框、**页顶搜索框留空提交直接进 `/search` 浏览全库**、目录树的展开/高亮与滚动跟随（滚动时自动收起不在当前浏览位置的分支，用户手动点开的分支不收起）、右下角“回到顶部”悬浮按钮（按钮写在 HTML 里，无 JS 时是普通的 `#top` 链接，滚动 400px 后 JS 才淡入）、条文“复制全文”、打印友好样式。（检索框本身是一个普表单，没有实时下拉建议；给第三方用的建议接口是 `/api/suggest`。）

**顶部导航只有五项**：首页 · 编 / 门类 · 疑难注解 · 指导性案例 · 关于数据。检索不占导航位（它是一个动词），进检索页走右侧搜索框：输入关键词→带 `?q=`；留空→干净的 `/search`（无 JS 也不变：`server/index.js` 把 `/search?q=` 302 到 `/search`）。
